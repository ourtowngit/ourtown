# Rail Network to the Dakotas

The whitepaper proposes using existing rail connections to extend the initiative westward from Minnesota into the Dakotas.

## Rail Connections

The proposed network references:

- Twin Cities & Western Railroad (TCWR)
- Sisseton Milbank Railroad (SMR)
- Red River Valley & Western Railway (RRVW)

## Regional Scale

Extending the network would allow the localized hub model to operate across a broader agricultural geography.

This creates a potential regional structure for [[Collection Hubs]], processing facilities, and renewable fuel supply.
