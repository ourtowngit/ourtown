# SAF Framework

The SAF framework is the agricultural and infrastructure side of CarbonShare.

It asks how a regional system could connect:

**farmers → oilseed crops → collection hubs → processing → oil / bio-crude / meal → rail → downstream fuel markets**

The original whitepaper proposes this framework as a rural-development strategy as well as a fuel strategy.
