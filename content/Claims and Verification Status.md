# Claims and Verification Status

This page records how CarbonShare treats important statements.

| Topic | Status | Treatment |
|---|---|---|
| Microsoft carbon-negative-by-2030 commitment | Verified | State as fact with Microsoft source |
| Microsoft $1B Climate Innovation Fund | Verified | State as fact with Microsoft source |
| Microsoft 2025 “moon has gotten further away” | Verified | Quote/attribute to Microsoft |
| IATA net-zero-by-2050 aviation commitment | Verified | Attribute to IATA |
| 2026 SAF production = 2.4 Mt / 0.8% | Verified | Use current IATA estimate |
| SAF could provide up to 65% of aviation reductions | Verified as IATA's assessment | Attribute to IATA |
| Farmers spent 20% of time producing energy | Not verified | Do not publish as fact |
| Historical farm energy examples | Supported | Keep with historical sources |
| Oil is finite | Basic physical fact | Avoid unsupported depletion prediction |
| Oil becoming harder to find/drill/transport | Too broad | Rewrite around exposure to purchased fuel |
| Corporate carbon demand can benefit farms | Proposition | Present as question/thesis |
| Biochar can generate carbon-removal credits | Conditional/verified methodology | Explain eligibility requirements |
| Waste heat recovery | Verified technology | Economics are site-specific |
| Winter camelina as SAF feedstock | Supported research | Treat economics/pathway as questions |
| Local processing increases rural value | Thesis | Test with economic model |
| Processing creates jobs | Supported mechanism | Quantify project by project |
| Rural revitalization from new processing | Central thesis | Present as hypothesis |
| 60+ Minnesota agricultural cooperatives | Superseded | Use USDA 2022 figure of 143 |
| Minnesota cooperative history | Verified | Cite UMN/MNHS |
| 150+ Minnesota canneries in 1960s | Not verified | Replace with documented 37 factories by 1947 |
| Diesel/peanut-oil 1900 demonstration | Verified | State precisely |
| Highway 212 / TC&W connection | Verified | Describe network accurately |
| TC&W directly connects to Pine Bend | Not established | Do not claim |
| Pine Bend fuel/jet-fuel infrastructure | Verified | Use as downstream regional node |
