# Rural Value Creation

CarbonShare is ultimately concerned with where value is created and where it remains.

## Central question

> **When agricultural commodities, energy, and carbon-related environmental attributes are produced in rural areas, how much of the resulting economic value returns to the communities that produce them?**

## Central thesis

> **More agricultural value can remain in rural communities when more of the processing occurs near the farm.**

This is a thesis to test with project-level economics.

Potential value streams include:

- farm commodity revenue;
- processing revenue;
- oil and fuel products;
- animal-feed co-products;
- carbon-removal products where eligible;
- recovered energy;
- logistics;
- construction;
- permanent operations jobs.
